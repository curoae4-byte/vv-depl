# 🎬 VALERY VISUALS — Portfolio

Современное высокотехнологичное портфолио/лендинг, созданное для демонстрации визуального контента (Cinematic, Fashion, Music Videos). Проект сфокусирован на плавной навигации, иммерсивном пользовательском опыте и кинематографичной эстетике.

## ✨ Особенности

- **Иммерсивный скролл**: Использование `Lenis` для мягкого и естественного скролла.
- **Кинематографичные анимации**: Сложные сцены на `GSAP` (ScrollTrigger), включая 3D-эффекты и параллакс.
- **Микро-взаимодействия**: Плавные переходы и UI-анимации с помощью `Motion`.
- **Оптимизация видео**: Кастомный видеоплеер и ленивая загрузка медиа-контента.
- **Типографика**: Использование кастомных шрифтов для уникального брендинга.

## 🛠 Технологический стек

- **Core**: React 19 + TypeScript
- **Build Tool**: Vite 7
- **Styling**: Tailwind CSS (v4)
- **Animation**: 
  - [GSAP](https://gsap.com/) (ScrollTrigger) — сложные таймлайны и скролл-сцены.
  - [Lenis](https://lenis.darkroom.engineering/) — плавный скролл.
  - [Motion](https://motion.dev/) — UI анимации и модальные окна.
- **Routing**: React Router 7

## 🚀 Быстрый старт

1. **Установка зависимостей**:
   ```bash
   npm install
   ```

2. **Запуск в режиме разработки**:
   ```bash
   npm run dev
   ```

3. **Сборка проекта**:
   ```bash
   npm run build
   ```

## 📦 Развертывание

Проект настроен для автоматизированного деплоя на **GitHub Pages** (ветка `gh-pages`).

```bash
# Одной командой: сборка + деплой содержимого dist в ветку gh-pages
npm run deploy
```

При запуске `npm run deploy` автоматически выполнится `npm run build`, а затем содержимое папки `dist` будет отправлено в ветку `gh-pages`.
